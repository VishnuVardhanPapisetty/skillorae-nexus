# NEXUS Hackathon Demo Checklist

## Before the Demo

- Set `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, and server-only `GEMINI_API_KEY` in the deployment environment.
- Confirm Supabase Auth works for the demo student and faculty accounts.
- Verify every demo student has exactly one `student_users` mapping and that RLS restricts student reads to linked records.
- Verify `faculty_users` authorization and faculty-only academic update policies in Supabase. This repository does not include SQL migrations or policy definitions.
- Add one academic record with known attendance, marks, and assignment completion values, plus one record with missing values.
- Run `npm run build`, `npm run test:engines`, and `npm run test:routes` before presenting.

## Demo Flow

1. Sign in as a student and confirm the displayed name, branch, and year match the linked student record.
2. Open Analyze. Show that identity and faculty-managed metrics are read-only; show missing metrics as unavailable. Enter personal interests and skills, and note that CGPA is self-reported and personal profile progress is browser-local.
3. Select a career and review the dashboard's readiness, faculty-verified academic metrics, skill gaps, recommendations, and saved simulation.
4. Sign in as authorized faculty, update one academic metric, then reload the student dashboard and confirm it reflects the database value.
5. Generate the AI report. A successful provider response is labeled `Gemini-generated report`; if Gemini is unavailable, the deterministic output is labeled `Deterministic NEXUS fallback`.
6. Visit the roadmap, recommendations, and simulation pages, then verify navigation back to the dashboard.

## Safety Checks

- Do not demonstrate with real student personal data unless you have permission.
- Confirm one student cannot read another student's profile or academic record.
- Confirm an unmapped account cannot use the student dashboard or AI report endpoint.
- Never show environment files, API keys, passwords, access tokens, or browser storage during screen sharing.
- Do not describe a fallback report as generated by Gemini.
